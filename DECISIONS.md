# Decisions

Deliberate deviations and choices, with the reversal condition for each.
Implementation mechanics live in the code and docs/MAINTENANCE.md.

## Runtime: Node and an isolated QuickJS VM

The vision proposed Bun with a shadowing preamble. We use strict TypeScript on
pinned Node, with QuickJS compiled to WebAssembly; only JSON crosses the host
bridge, and no module loader or host filesystem, process, timer, or network
binding exists. A Node `vm` context does not give the same separation. Revisit
if another runtime provides equal isolation with simpler packaging.

## Replay records deliveries as well as invocations

Resolving cached calls in invocation order changes later prompts when agents
originally finished out of order, so `replay.jsonl` records starts and
deliveries and replay follows prior delivery order. Imposing a stage barrier was
rejected because it changes pipeline semantics. First mismatch switches the
suffix to live execution irreversibly.

Cancellation semantics follow from this: a stopped run reruns its interrupted
suffix, an intentional skip stays cached as null, and ordinary terminal failures
(timeouts, exhausted corrections, confirmed subscription exhaustion) stay cached
rather than being silently retried. Edit the prompt/options or start a fresh run
to retry. Replay cannot guarantee exactly-once external side effects after a
crash.

## Keep original schema semantics

Every backend's output is validated against the caller's schema without
coercion, default injection, or removal of extra fields. Codex uses native
output only when the schema already meets its strict structural requirements;
otherwise it falls back to prompted output with local validation. Schemas are
JSON Schema draft-07 with local references only; root-object and required-subset
violations and proven contradictions are rejected at call time, but full
satisfiability of arbitrary schemas is not claimed.

Schema correction never resends the original task: ACP retains its session and
receives only validation feedback; CLI drivers get a fresh formatting turn with
the prior result, the error, and the schema, under read-only restrictions and
without the task. ACP cannot enforce read-only corrections, so correction tool
calls there are logged with a warning. Exhausted corrections return null. CLI
resume flags were rejected for introducing persistent vendor sessions;
reconsider if a probed multi-turn CLI transport offers a simpler contract.

## Deferred budget

`budget.total` is null, `spent()` is zero, and `remaining()` is Infinity; actual
usage is still reported. The reference budget is scoped to a launching
conversation turn, which a standalone CLI does not have. Enabling a hard ceiling
requires reliable per-backend accounting and recorded budget observations for
faithful replay.

## Native ACP means prompted output

OpenCode, Kimi, and Qwen use their native ACP servers, one process per leaf,
which bounds crash and cancellation effects to one agent. ACP has no native
schema facility, so these backends use prompted output. ACP tool policies are
unsupported and requested restrictions fail closed rather than disappear.

Discovery opens an empty vendor session without sending a model prompt, because
ACP sessions expose model-dependent settings that CLI catalogs omit; revisit
when session-free discovery exposes the same surface. Default model markers are
shown only when observed: Claude and Codex catalogs do not report the configured
default, so omission delegates to vendor configuration.

## Child source selection

Literal child references are resolved and loaded before leaf work; computed
references resolve at first use, which supports children generated by an earlier
agent. A resume prefers an existing current source and falls back to the prior
run's verified archive only when the original is absent, with a warning. Always
freezing old source would hide deliberate edits; requiring originals would
strand generated children.

Worktree cleanup compares ignored files against their post-setup baseline:
changed or new ignored content is preserved, unchanged copies can be removed.
Cached worktree metadata is historical; resume does not recreate deleted
worktrees.

## Preflight static references; validate computed references at call time

A backend or child path computed from a model result cannot be known at launch.
The CLI preflights the default and statically visible selections, and checks
computed selections at the call boundary. Restricting JavaScript to make
complete static discovery possible would break script portability.

## Process support

Each backend runs under a small Node supervisor that anchors its process group
and kills the group when the vendor exits or the owner's IPC connection dies.
SIGTERM allows a one-second grace period; post-exit output draining is bounded
to one second, and uncertain cleanup fails the run and preserves its worktree.
This avoids PID registries and process-list reconstruction. Descendants that
deliberately create new sessions are outside process-group containment; this is
not an OS sandbox. Windows requires WSL until equivalent Job Object process-tree
ownership is implemented.

## Foreground and background run control

A standalone command runs in the foreground by default to compose with shells
and CI; `--background` returns a run ID after preflight, and `wait`, `stop`, and
`skip` operate on that run over a token-authenticated loopback connection. A
reused PID is never authorization to signal a process. Always-background
operation was considered and rejected because it forces a second command for
every result; revisit if harness usage favors it.

## Explicit resource and layer overrides

There is one override surface per runtime layer: `sandbox` (memory and
instruction limits, never new host APIs), `transport` (agent, discovery, and
background-startup deadlines), `schemaStrategy` (can force prompted output), and
`sharedPaths` (opted-in local state for worktrees). Agent attempts have no
default deadline, matching the reference: long builds outlast any fixed limit
and a killed agent loses its work, while `skip` and `stop` end a genuinely stuck
agent and `agentTimeoutMs` sets a deadline when one is wanted.

## Progressive disclosure and cached artifacts

Progress activity is coalesced at 250 ms; full streams always remain in
transcripts. `show` lists agent metadata, `--agent` expands one result, and
`--transcript` follows cached transcript lineage. The journal matches all agent
options, including labels and phases, plus effective runtime settings and cwd,
so changing any of them cannot silently reuse an outcome produced under a
different execution contract. Old run artifacts must remain available to read
cached transcripts.

## Reference logging contract

The reference authoring skill specifies `log(message: string): void`, and
coercion of other values is not documented, so the CLI keeps the string
contract. Cached journals and transcripts remain readable on resume; changed
worktrees are not recreated.

## Discovery and minimal authentication

Literal profile and backend selections are preflighted; concurrent computed
selections share one in-flight discovery owned by the root run, so skipping one
leaf cannot cancel sibling discovery. Claude `--bare` mode disables
OAuth/keychain authentication, so `minimal` is advertised only with a nonempty
`ANTHROPIC_API_KEY`; automatically running API-key helpers during discovery was
rejected, and helper-only setups are conservatively unsupported. Correction
turns preserve the original tool allow/deny restrictions even when their
read-only intersection is empty.

Cursor's terminal result aggregates earlier narration, so its final assistant
message after tool activity is the return value, falling back to the terminal
aggregate only when no such message exists. Revisit if the vendor changes
assistant events to text deltas.
